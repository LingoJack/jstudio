# Quickstart: 验证代码块内 Cmd+A 全选代码

**Feature**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md) |
**Contract**: [contracts/keyboard-interaction.md](./contracts/keyboard-interaction.md)

本指南提供端到端的手动验证场景，用于确认功能按 spec 与交互契约正常
工作。项目当前无前端自动化测试框架，故以下均为手动交互步骤；每个
场景对应 `contracts/keyboard-interaction.md` 行为矩阵中的一行。

## 前置准备

```bash
cd /Users/jacklingo/dev_custom/jstudio
npm install         # 若未安装依赖
npm run tauri:dev    # 启动开发模式（或 make dev）
```

打开应用后新建一篇文档，插入至少 2 个代码块（可用 `/code` slash
命令或 Markdown ``` 语法触发），分别填入不同语言的多行代码，例如：

- 代码块 A（JavaScript，3 行）
- 代码块 B（Python，1 行）
- 代码块 C（留空，不输入任何内容）

再在代码块前后各插入一个普通段落，包含一些文字。

## 验证场景

### 场景 1 — 光标在代码块内，按 Cmd+A 只选中该块（对应矩阵 #1）

1. 点击代码块 A 内任意位置，将光标放在代码文本中间。
2. 按下 Cmd+A（macOS）/ Ctrl+A（Win/Linux）。
3. **预期**：代码块 A 的全部文本被高亮选中；高亮范围不超出代码块 A
   的边框，前后段落及代码块 B/C 均无高亮。

### 场景 2 — 全选后复制，剪贴板内容与源文本一致（对应契约后置条件）

1. 承接场景 1 的选中状态，按 Cmd+C 复制。
2. 粘贴到系统其他文本编辑器（或应用内新段落）。
3. **预期**：粘贴内容与代码块 A 的原始代码逐字符一致，不含多余的
   前后内容。

### 场景 3 — 全选后输入替换选中内容（对应 FR-004）

1. 承接场景 1 的选中状态，直接输入一个字符（如 `x`）。
2. **预期**：代码块 A 原内容被替换为该字符；代码块前后段落、其他
   代码块内容不受影响。

### 场景 4 — 三击整块选中后按 Cmd+A（对应矩阵 #3，Edge Case）

1. 在代码块 B 内快速三击（triple-click），确认代码块进入
   `.is-selected` 整块选中状态（通常有边框高亮，非文本高亮）。
2. 按下 Cmd+A。
3. **预期**：代码块 B 的文本内容被选中（等同场景 1 的效果），而不是
   意外选中整篇文档。

### 场景 5 — 空代码块内按 Cmd+A（对应矩阵 #4）

1. 点击代码块 C（空代码块）内部以放置光标。
2. 按下 Cmd+A。
3. **预期**：无报错、无崩溃；由于内容为空，视觉上无可见高亮或高亮
   区域为空；代码块前后内容不受影响。

### 场景 6 — 光标在代码块之外按 Cmd+A（对应矩阵 #5，回归验证）

1. 点击代码块 A/B/C 之外的任意正文段落，放置光标。
2. 按下 Cmd+A。
3. **预期**：与本功能上线前一致——选中整篇文档的全部内容（所有
   段落 + 所有代码块），而不是仅选中当前段落。

### 场景 7 — 语言搜索输入框聚焦时按 Cmd+A（对应矩阵 #6）

1. 点击某代码块右上角的语言徽章（language badge），打开语言下拉
   搜索框。
2. 在搜索框内输入若干字符（如 `java`）。
3. 将光标定位到搜索框文本中间，按 Cmd+A。
4. **预期**：仅搜索框内的文本被选中（浏览器原生 input 全选行为），
   代码块的代码内容不受影响，下拉列表也不会意外关闭或跳转。

### 场景 8 — HTML/Mermaid 渲染预览模式下的行为（对应矩阵 #7）

1. 新建一个 HTML 或 Mermaid 代码块，填入一段有效的 HTML/Mermaid 源码。
2. 点击代码块工具栏的"预览"按钮，切换到渲染预览模式（源码被隐藏，
   显示渲染结果）。
3. 点击预览区域使该代码块进入选中态，然后按 Escape 或点击预览覆盖层
   退回编辑状态（或直接切回源码视图）。
4. 切回源码视图后，点击代码内部放置光标，按 Cmd+A。
5. **预期**：与场景 1 行为一致——代码块全部源码被选中；整个过程无
   报错、无内容丢失。

### 场景 9 — 跨分段选区激活态下点击代码块的边界行为（对应矩阵 #8）

> 仅当文档启用了分段编辑器（长文档自动分段）时适用；若测试文档较短
> 未触发分段，可跳过此场景。

1. 在长文档中，用鼠标从一个分段拖选到另一个分段，制造一个跨分段
   选区（`useCrossSectionSelection` 激活态）。
2. 松开鼠标后，直接点击某个代码块内部放置光标。
3. 按下 Cmd+A。
4. **预期**：代码块内全选生效（等同场景 1），说明点击代码块已正确
   清除了先前的跨分段选区激活态，两个系统之间无状态残留冲突。

## 验收标准汇总

全部 9 个场景需全部通过（无报错、无崩溃、选区范围符合预期）方可认为
本功能验证完成，可进入 `/speckit.tasks` 阶段拆分实现任务。
