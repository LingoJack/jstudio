## unlisted deps 隐患已消除（用户追问后执行）
- knip 报 9 个 unlisted import 位点，去重为 **5 个独立包**：`@tiptap/extension-code`(3处)、`@tiptap/extension-list`(3处)、`linkifyjs`、`pdfjs-dist`、`hast`(type-only)。
- 排查方法要点：`hast` 代码写 `import type from 'hast'`，但 `node_modules/hast` 不存在，靠 `@types/hast` 的 @types 自动解析——属隐性类型依赖，必须修成 `@types/hast` 直接 devDep；其余 4 个是运行时传递依赖。
- 修复：用 `npm install <pkg>@<lockfile解析版本> --save`（运行时）和 `--save-dev`（@types/hast@3.0.4）提升为直接依赖，版本锁定到当前实际解析版本（@tiptap 3.27.1 / linkifyjs 4.3.3 / pdfjs-dist 5.4.296）。`package-lock.json` 仅净增 31 行。
- 结果：knip 的 `Unlisted dependencies` 段消失，tsc 绿。提交 `790e65f`。
- 可复用眼：knip `unlisted dependencies` → 先 `npm ls <pkg> --all` + 查 lockfile 真实版本，再用 `npm install <pkg>@<version> --save` 提升，最后重跑 knip 确认段消失。type-only 的裸包名（如 hast）要对应加 `@types/<x>`。
