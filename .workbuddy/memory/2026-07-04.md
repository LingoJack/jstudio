# 2026-07-04

## 时序图连接点优化（DiagramBlockView / GraphCanvas）

用户反馈时序图两个问题并修复：

### 问题 1：画线点样式
- lifeline 中心线上一长串实心蓝点（8px，每 20px 一个）悬停时视觉杂乱。
- 优化：
  - `graphTheme.ts::createConnectionPointSVG` 实心蓝点 → "白底+蓝环+蓝心"靶心风格（浅色白底、深色 `#1F2937` 底），在虚线生命线上更精致不抢眼。
  - `GraphCanvas.tsx::getAllConnectionConstraints` 生命线连接点间距 20px → 40px，降低密度。

### 问题 2："服务"时序块只有中间能连
- 根因两处：
  1. `customShapes.ts::LifelinePerimeter` 把所有连接点 x 强制中心线、且把头部区域（y < HEAD_HEIGHT）y 压到头部底部 → 头部只能连底部中心。
  2. `GraphCanvas.tsx::getAllConnectionConstraints` lifeline 连接点 y 从 HEAD_HEIGHT 开始，头部矩形内不生成任何连接点。
- 修复：
  - `LifelinePerimeter` 重写：next.y < lineTop 时按矩形 perimeter 投影到头部框最近边（上/下/左/右），让头部块可连任意边；头部下方仍走中心线。
  - `getAllConnectionConstraints` 为 lifeline/umlActor 头部矩形补连接点：顶部中点 (0.5,0)、左中 (0, headMidY)、右中 (1, headMidY)；底部中点已含在生命线首点，跳过去重。

### 知识点
- maxGraph 连接机制：`getAllConnectionConstraints` 决定悬停时显示哪些可连接点（候选），`Perimeter` 函数决定连线端点最终坐标。两者配合：constraints 提供候选位，perimeter 把端点投影到形状边缘。
- `constraintHandler.pointImage` 是全局的，无法按形状区分连接点图标样式。
- GraphCanvas.tsx:495-497 `getDefaultPlugins` + `ConstraintHandler` 有预先存在的 TS 类型错误（缺 pluginId），但项目能正常运行，非本次引入。
