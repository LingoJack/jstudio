# 2026-07-09 工作日志

## IME 切换英文时拼音去空格（终端 + 编辑器）

需求：中文输入法输入拼音过程中切换到英文输入法，当前候选框里的原始拼音串（如 "ni hao"，带分词空格）会被 IME 整体提交到光标。期望去掉空格（"nihao"）再插入。

实现：
- 新建共享 util `src/lib/ime/pinyinStrip.ts`：`isRawPinyinCommit(data)`（含空格 + 全 ASCII 字母/空格 + 含字母）+ `stripPinyinSpaces(data)`。正常选词提交是中文无空格，不受影响。
- **终端侧** `useTerminalManager.ts`：xterm compositionend 后用 `setTimeout(0)` 读 textarea.value → onData，所以 preventDefault 对 compositionend 无效。改在 `bridgeCompositionEnd` 记录 `lastCompositionEndData`，`term.onData` 里精确匹配（`data === lastCompositionEndData` + 120ms 时间窗口 + 拼音特征）后用去空格版本 `ptyWrite`。消费一次即清空，避免误伤粘贴。
- **编辑器侧** `imeCapsLockFix.ts`：扩展原 CapsLock 幻影字符插件，新增独立于 CapsLock 的拼音去空格逻辑。compositionend 检测拼音带空格 → beforeinput(insertText) 里 `view.dispatch(tr.insertText(cleaned))` + preventDefault。handleTextInput 加对称 fallback。BlockEditor + sectionEditor 都注册了该扩展，改一处全覆盖。
- `npx tsc --noEmit` 通过，零错误。
