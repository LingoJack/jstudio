# 2026-09-19

## mermaid 时序图 lifeline 截断 bug 修复 + Cmd+滚轮缩放（desktop）

- **根因**：mermaid 11.16.0/11.17.2 的 sequence renderer 把每条生命线写死为 `attr("y2", 2e3)`（class 叫 `actor-line 200`），图高超过 2000 user units 时生命线停在半空，下半段消息/Note/opt 框没有生命线。矮图因 viewBox 裁剪看不出。上游 11.x 未修，v12 是大版本重绘不采用。
- **修复**：渲染后处理 `mermaidLifelineFix.ts::fixSequenceLifelines(svg)`——把距 viewBox 底部落差 >200 的 `.actor-line` 延长到 viewBox bottom+20（被裁剪，与矮图行为一致）；mirrorActors:true 的设计间隙 ~75px 不会被误改。在 `useMermaidPreview` 单一收口点生效（编辑器内预览 + 独立预览窗口共用同一 svg 字符串）。附带修了 render id 毫秒级碰撞 + 快速输入乱序渲染（cancelled guard）。
- **验证方法**：用仓库 electron + esbuild 打包真实 `mermaidConfig` 渲染用户真实图表（从 `~/.jdata/studio/studio.db` documents.body 只读取出 code block content，content 是 `[{annotations, text}]` 段数组），量 lifeline y2/contentBottom/viewBox。修复后 6 条生命线全部 y2=3444（vbBottom 3424+20）。
- **缩放**：新组件 `MermaidViewer.tsx`（react-zoom-pan-pinch 4.2.0，peer react *）。编辑器内 mermaid 预览块与预览窗口共用。Cmd/Ctrl+滚轮（触控板捏合=ctrlKey）光标锚定缩放 `zoomToPoint(scale, x, y, 0)`（animationTime=0 是瞬时的，lib `animate()` 有专门分支）；窗口模式普通滚轮 `panBy` 平移，编辑器模式普通滚轮放行给页面；双击 reset；窗口有 −/+/⊗ 工具栏。删除了手搓的 `mermaidWindowHtml.ts`。
- **坑**：本机 shell 有 `ELECTRON_RUN_AS_NODE=1`，直接跑 electron 二进制会退化成 node，必须 `env -u ELECTRON_RUN_AS_NODE`；esbuild 打包 /tmp 下的 entry 解析不到 desktop 的 node_modules，mermaid 用绝对路径 import + `--loader:.mmd=text`；React onWheel 是 passive，必须原生 `addEventListener('wheel', …, {passive:false})` 才能 preventDefault 掉 Chromium 的 ctrl+wheel 页面缩放。
- 诊断中间态：`/tmp/mermaid-repro/`（临时，可删）。

## 补充：拖拽平移改为自实现（MermaidViewer 二次修复）

- 用户反馈"右键拖不动"。根因：react-zoom-pan-pinch v4 的 `isPanningStartAllowed` 里 `isEditableTarget` 用 `element.closest('[contenteditable="true"]')` 判定，编辑器内 mermaid 预览的祖先链上必有 ProseMirror contenteditable="true" 根 → lib 内置 pan（所有按键）在编辑器内永远拒启；`closest` 不会停在 contenteditable="false" 边界。
- 解法：`panning={{ disabled: true }}` + `doubleClick={{ disabled: true }}` 关掉 lib 内置项，自己在 MermaidViewer 里用原生 mousedown/mousemove/mouseup（move/up 挂 window）驱动 `panBy(dx, dy, 0)`，dblclick 自己调 `resetTransform()`。左/中/右键都能拖（`PAN_BUTTONS` = {0,1,2}），mousedown preventDefault 挡文字选择和中键 autoscroll，右键菜单由 main.tsx 全局 handler 兜底。注意 React 合成事件的 stopPropagation 挡不住 PM（PM 原生监听在 React root 容器之下，先于合成事件触发）——此处无需挡 PM：code block 不可拖拽，PM 对非可编辑区的 mousedown 是无害的。
