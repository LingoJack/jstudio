# 2026-07-08

## CollapsibleView 标题无法输入文字 bug 修复

**文件**: `src/components/editor/nodes/CollapsibleView.tsx`

**根因**: 折叠块标题 `<input>` 在 ProseMirror `view.dom` 内部。原代码只 shield 了
`mousedown` 和导航键 `keydown`，但**漏掉了 `beforeinput` 事件**。

现代浏览器（含 WKWebView）通过 `beforeinput` (InputEvent) 传递文本输入。ProseMirror
在 `view.dom` 上的 `beforeinput` 处理器**不检查 target 是否是表单控件**——它假设所有
冒泡上来的 `beforeinput` 都是编辑器内容输入，调用 `preventDefault()` 并尝试自行插入
文本。这会取消浏览器对 `<input>` 的原生字符插入 → 后续 `input` 事件不触发 → React
的 `onChange` 不运行 → 标题看起来完全无法输入。

**修复**: 在 wrapper 元素上添加原生 bubble-phase 的 `beforeinput` / `compositionstart`
/ `compositionupdate` / `compositionend` 监听器，当 target 是表单控件时
`stopPropagation()`，阻止事件冒泡到 ProseMirror。

关键点：
- `stopPropagation` 在 wrapper（view.dom 的后代）上执行，先于 ProseMirror 的监听器
- `beforeinput` 的 stopPropagation **不影响**独立的 `input` 事件，因此 React 的
  onChange（监听 `input` 事件）仍能正常触发
- composition 事件也需要 shield，否则中文/日文/韩文输入法会被 ProseMirror 劫持
- keydown 只需 shield 导航键（Arrow/Backspace/Delete/Tab/Home/End），普通字符键在
  keydown 阶段无害，因为 ProseMirror 通过 beforeinput 处理文本插入
