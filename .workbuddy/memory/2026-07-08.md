## CollapsibleView 标题无法输入文字 bug 修复

**文件**: `src/components/editor/nodes/CollapsibleView.tsx`

**根因（两层）**:
1. ProseMirror 在 `view.dom` 上的 `beforeinput` 处理器不检查 target 是否表单控件，
   对所有冒泡上来的 beforeinput 调用 `preventDefault()`，取消浏览器对 `<input>` 的
   原生字符插入。
2. 即使 shield 了 beforeinput，`input` 事件仍冒泡到 ProseMirror 的
   `editHandlers.input`，其调用 `domObserver.flush()` 可能触发 NodeView 重新渲染，
   导致受控组件 `value` 被重置回旧值——字符"闪现后消失"。

**最终修复（三管齐下）**:
1. **非受控 input**：`defaultValue` + `ref` 替代 `value` + `onChange`，浏览器直接管理
   值，不依赖 React state，扛住任何 ProseMirror 触发的重渲染。移除了 `useState`。
2. **shield 全部相关事件**（wrapper 上原生 bubble-phase stopPropagation）：`mousedown`
   / `keydown`(导航键) / `beforeinput` / `input` / `compositionstart|update|end`。
3. **原生 `input` 监听器**挂在 `<input>` 元素本身（target 阶段，先于 wrapper 的
   stopPropagation），通知 cursor trail `markDirty()`。

外部同步：`useEffect([summary])` 在 input 未聚焦时手动 `el.value = summary`。
提交：`commitSummary` 从 `inputRef.current.value` 直接读取。

**教训**：在 ProseMirror NodeView 内放原生 `<input>` 时，受控组件不可靠——必须用
非受控 + 全量事件 shield。此模式可复用于其他含表单控件的 NodeView。
