- **背景**: 上一轮优化了工具栏按钮图标，但拖拽绘制时的预览仍是普通 div 方框（border+固定圆角），无论选什么形状都画矩形轮廓 → 用户点椭圆拖拽时预览还是方形，与将绘制的形状不一致。
- **文件**: `src/components/editor/nodes/graph/GraphCanvas.tsx`、`src/styles/vscode-theme.css`
- **改动**:

## 画板 Alt/Option 复制拖动诊断与视觉反馈

- **背景**: GraphCanvas 已设 `graph.isCloneEvent = (evt) => evt.altKey`（Mac 的 Option 即 Alt，altKey 标准上能反映 Option），理论上 Option+拖动应触发复制。但用户反馈没生效，怀疑 Mac Option 相关。
- **排查**: InternalMouseEvent.getEvent() 返回原生 MouseEvent，altKey 不会丢失；maxGraph 的 SelectionHandler 在 mouseMove/mouseUp 均会调用 isCloneEvent 重新读 altKey，逻辑正确。故判定按键检测本身没问题，缺的是可见反馈——用户拖动时看不到「这是复制」的提示，误以为没生效。
- **文件**: `src/components/editor/nodes/graph/GraphCanvas.tsx`、`src/styles/vscode-theme.css`
- **改动**:
  - 新增 `altHeld` state + window 级 keydown/keyup 监听（监听 key==='Alt'，window 而非 root 保证拖动中焦点在子元素时也能捕获；blur 时复位）。
  - root className 在 altHeld 时加 `is-alt-held`。
  - CSS 新增 `.jgraph-canvas-root.is-alt-held:not(.is-drawing) .jgraph-surface { cursor: copy }`：按住 Option 悬停画布时光标变「复制」光标（带 + 号），画图模式优先用十字不冲突。
- **效果**: 按住 Option 时光标变复制光标 → 确认按键检测通；若光标变了但复制仍未发生则问题在 maxGraph 拖动路径。
- **验证**: `npm run lint`(tsc --noEmit) 通过。

## 画板网格持久化 + 复制拖动诊断日志

- **背景**: 用户反馈 1) Option+拖动复制仍不生效（光标变 + 号了但没真复制）；2) 网格开关切换后重新挂载（如切文档回来）会丢失。
- **网格持久化**: 扩展 GraphSnapshot 加 `showGrid?: boolean` 字段，随 snapshot 序列化/反序列化。
  - graphSnapshot.ts: GraphSnapshot 加 showGrid；parseGraphSnapshot 读出；serializeGraphSnapshot 加参数写入。
  - graphModel.ts: readSnapshotFromGraph(graph, showGrid?) 写入返回快照；applySnapshotToGraph 读 snap.showGrid 调 graph.setGridEnabled。
  - GraphCanvas.tsx: showGridRef（同步组件 showGrid 态）；emitSnapshot 传 showGridRef.current；applySnapshot effect 读 snap.showGrid 调 setShowGrid；toggleGrid 切换时同步设 showGridRef + 触发 emitNowRef.current() 持久化（用 emitNowRef 桥接绕过 const TDZ——toggleGrid 定义早于 scheduleEmit）。
- **复制诊断日志**: 在 isCloneEvent 重写处加 console.log 打印 altKey 返回值；container 加捕获阶段 mouseup 监听打印 altKey/选中数/isCloneEvent 返回。用于确认 maxGraph 内置 clone 路径是否被触发、为何不生效。
- **验证**: `npm run lint`(tsc --noEmit) 通过。待用户跑 dev 看 console 日志反馈后定位 clone 根因。

## 修复网格持久化在首次挂载时仍丢失

- **根因**: 首次挂载走初始化 effect（依赖 `[]`），它调用了 `applySnapshotToGraph`（设了引擎 `gridEnabled`）但**没同步组件 `showGrid` state**。而 `showGridRef.current = showGrid` 每次渲染都执行，state 仍是默认 true → 覆盖 ref → 下次 emit 又把 showGrid 写成 true → 网格"复活"。
- **修复**: 初始化 effect 里 parseSnapshot 后，若 showGrid 是 boolean 则调 `setShowGrid` + 同步 `showGridRef.current`。
- **验证**: `npm run lint`(tsc --noEmit) 通过。
