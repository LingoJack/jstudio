## 优化画板(GraphCanvas)工具栏体验

- **背景**: DiagramBlockView 自研画板内核 GraphCanvas 的工具栏有三个体验问题：形状按钮用 lucide 抽象图标不能预览实际形状；工具栏左侧竖排与主流画图工具习惯不符；`rectangle` 和 `rounded` 都用 lucide 的 `Square` → 出现两个一模一样的方形，圆角完全丢失。
- **文件**: `src/components/editor/nodes/graph/GraphCanvas.tsx`、`src/styles/vscode-theme.css`
- **改动**:
  - 新增 `ShapeGlyph` 组件，按 shape 渲染真实形状预览（直角矩形/圆角矩形 rx=2.5/宽椭圆/菱形/T字），用 `stroke="currentColor"` 描边 → 自动跟随按钮文字色适配明暗主题，描边宽 1.5 对齐 graphTheme.SHAPE_STROKE_WIDTH。
  - `shapeTools` 去掉 `icon` 字段，按钮渲染改用 `<ShapeGlyph shape={shape} />`；移除不再使用的 lucide 导入（Square/Circle/Diamond/Type as TypeIcon）。
  - CSS `.jgraph-toolbar` 从 `flex-direction:column`（左侧竖排）改为 `row`（顶部居中浮动 `left:50% + translateX(-50%)`，加 `max-width:calc(100%-16px)` 兜底）。
  - `.jgraph-tool-sep` 分隔符从横向 `height:1px` 改为竖向 `width:1px;height:20px`。
- **验证**: `npm run lint`(tsc --noEmit) 通过，移除图标导入后无遗漏引用。

## 画板拖拽预览改为跟随形状轮廓

- **背景**: 上一轮优化了工具栏按钮图标，但拖拽绘制时的预览仍是普通 div 方框（border+固定圆角），无论选什么形状都画矩形轮廓 → 用户点椭圆拖拽时预览还是方形，与将绘制的形状不一致。
- **文件**: `src/components/editor/nodes/graph/GraphCanvas.tsx`、`src/styles/vscode-theme.css`
- **改动**:
  - 把预览元素从 `document.createElement('div')` 改为 `document.createElementNS(svg, 'svg')`。
  - 新增 `ensurePreviewShape(shape)`：按当前形状在 SVG 内创建对应几何元素（rectangle/rounded/text→rect、ellipse→ellipse、diamond→polygon），切换形状时重建，否则复用。
  - 新增 `applyPreviewSize(w,h,shape)`：把拖拽区域应用到形状属性——ellipse 设 cx/cy/rx/ry，diamond 设 points 顶点，rounded 设 rx/ry（封顶 SHAPE_ARC_SIZE 并随尺寸缩放），rect 设 width/height。
  - onMouseDown 调 ensurePreviewShape + applyPreviewSize(0,0)；onMouseMove 调 applyPreviewSize(w,h)，每次读取 pendingShapeRef.current 保证形状实时一致。
  - CSS：`.jgraph-draw-preview` 改为 SVG 适配（去 border/background/border-radius，保留定位+overflow:visible）；新增 `.jgraph-draw-preview-shape` 控制 fill/stroke/stroke-width(2)+`vector-effect:non-scaling-stroke`（描边不被 SVG 缩放）；新增 `.is-text-region` 虚线样式（text 实际无边框，用虚线表示文本区域）；暗色模式跟随主题。
- **验证**: `npm run lint`(tsc --noEmit) 通过。
