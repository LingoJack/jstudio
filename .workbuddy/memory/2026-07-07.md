## SectionedBlockEditor 空白区域点击误跳转修复
- 问题：点击标题下方 padding 区域会误触发跳转到文档末尾
- 原因：`handleBlankAreaClick` 事件绑定在滚动容器上，判断逻辑为"不在编辑器内"
- 解决：
  - 给尾部空白区域添加 `.click-to-focus-end` 标识
  - 改为只有点击该标识元素才触发跳转
  - 与 BlockEditor 行为保持一致

## 外部 HTML 粘贴样式过滤
- 问题：从外部网页复制内容粘贴时，HTML 样式（字体、颜色）被带入编辑器
- 原因：`editorPasteDrop.ts` 对非 Markdown 外部 HTML 返回 `false`，让 ProseMirror 默认处理
- 解决：
  - 新增 `cleanExternalHtml` 函数，解析 HTML 并移除样式相关属性（style/class/width/height/bgcolor/color/face/size）
  - 解包 `<font>` 和无语义 `<span>` 标签，保留语义结构（加粗、链接、列表、标题）
  - Markdown 格式仍优先解析，内部复制（有 `data-pm-slice`）保留完整结构
  - 避免"一刀切"转纯文本，保留有用的语义标记

## DocumentTabs Apple 风格切换动效
- 问题：Tab 切换无动效，用户体验平淡
- 解决：
  - 新增独立选中指示器（absolute-positioned pill），平滑滑动跟随当前 Tab
  - 使用 spring/bounce 缓动曲线 `cubic-bezier(0.34, 1.56, 0.64, 1)` 实现"duang duang"弹跳感
  - 指示器宽度动态适配目标 Tab 尺寸，`left` 和 `width` 同步过渡
  - 激活 Tab 不再设置背景色，由指示器统一承载视觉高亮
  - 监听 resize/scroll 事件，实时更新指示器位置
