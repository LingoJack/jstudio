# 2026-07-16

## 修复图片/文件 asset 协议跨域导致加载失败

- 问题：Tauri WebView 页面源为 `tauri://localhost`，`convertFileSrc` 默认生成 `asset://localhost` URL，WebKit 同源策略拒绝加载，控制台报 "Domains, protocols and ports must match"。
- 方案：新增 `useAssetBlobUrl` hook，对 `assets/…` 相对路径通过 `storage.readFileBytes` 读取字节并创建 `blob:tauri://localhost/…` URL，实现同源加载；`data:` / `http(s):` 透传。
- 改动文件：
  - `src/lib/editor/content/assetUrl.ts`：新增 `resolveAssetFilePath`。
  - `src/lib/editor/content/useAssetBlobUrl.ts`：新增 hook。
  - `src/components/editor/nodes/ImageView.tsx`：图片改用 blob URL，加载中/失败显示占位。
  - `src/components/editor/nodes/FileView.tsx`：内联 preview（html/pdf/image/audio/video/docx/text）改用 blob URL。
  - `src/lib/windows/previewWindow.ts`：`PreviewPayload` 增加可选 `docContext`。
  - `src/components/windows/PreviewWindowApp.tsx`：用 `docContext` 解析 blob URL。
- 验证：`npx tsc --noEmit` 通过。

## 修复 CodeBlockView HTML preview iframe 触发 SecurityError

- 问题：控制台报 `SecurityError: Sandbox access violation... lacks the "allow-same-origin" flag`，随后出现 `Should not already be working` React invariant 错误，页面卡死/切换文档无响应。
- 根因：`CodeBlockView` 的 HTML preview iframe sandbox 缺少 `allow-same-origin`，React 19 dev mode 访问该 iframe 时触发跨域安全错误并级联崩溃。
- 改动：`src/components/editor/nodes/CodeBlockView.tsx` 的 iframe sandbox 追加 `allow-same-origin`。
- 验证：`npx tsc --noEmit` 通过。
