## 小程序端 mermaid 时序图渲染（miniprogram/）

- 需求：CodeBlock 对 mermaid 代码块不再只显示源码，渲染效果对齐用户给的参考截图（mermaid 默认亮色主题、autonumber、上下镜像参与者、虚线返回、自环）。
- 根因约束：mermaid 官方库依赖 DOM/异步初始化，weapp 跑不了；桌面端 `desktop/src/components/editor/nodes/code-block/useMermaidPreview.ts` 走的是 mermaid.render。
- 方案：`miniprogram/src/lib/mermaid/sequenceParser.ts`（纯 TS 解析 sequenceDiagram 文本）+ `sequenceLayout.ts`（字符估宽 + 绝对定位布局）+ `components/blockView/MermaidSequenceView.tsx`（View 绝对定位渲染，线用 border/background，箭头用 CSS 三角/旋转方块，z 序：帧→生命线→激活→注释→消息→参与者盒）。CodeBlock.tsx 里 `language === 'mermaid'` 时解析布局成功则渲染图、失败或非时序图降级源码。
- 关键事实（从 mermaid v11 dist 产物 sequenceDiagram-*.mjs 的 jison 动作核实）：
  - 消息激活简写语义：`A->>+B` 激活目标 B（case 70）；`A->>-B` 关闭的是**发送方 A** 的激活段（case 71，activeEnd actor 取 $0-4=from），与直觉相反，官方示例 `John-->>-Alice` 结束的是 John 的段。
  - mermaid 默认主题值：参与者盒 #ECECFF / 边 #9370DB（mainBkg/border1），生命线 #999 0.5px 实线（svgDraw actor-line），消息/编号 #333（signalColor），注释 #fff5ad/#999。autonumber 圆点在发送端线内、自环圆点在回路右竖线上。
  - 生命线中心距按其间最长消息标签自适应（思路同桌面 sequenceConverter.computeGapSpacings）。
- 配色刻意固定为亮色（白底图页嵌在暗色代码卡里），不随 miniprogram 暗色主题变化；不缩放、超宽横向滚动（fit 缩放在手机上会让 14px 标签变 6-7px 不可读）。
- 验证：`make test`（新增 sequence.test.ts，24/24）、`make lint`（tsc+eslint 干净）、`npm run build:weapp` 编译通过。README 已知差异表已补条目。
- 未做（后续可扩展）：flowchart 等其他图类型、autonumber 的 wrap、box 分组视觉框、fit-to-width 缩放。
