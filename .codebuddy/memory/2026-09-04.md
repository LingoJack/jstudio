## 新建 self-improving skill（assets/skillhub/self-improving/）

用途：把任务中查明的根因、验证过的做法、用户定下的长期约束，固化为经验 doc 或新 skill。

- 条目格式固定五章：背景 / 表现 / 根因 / 解决 / 相关改动，可选「复用提示」；frontmatter 字段 title/date/area/tags/status(/source)。
- 目录约定：经验库 `<hub>/experiences/<area>-<slug>.md`，索引 `<hub>/experiences/INDEX.md`，新 skill 落在 `<hub>/<skill-name>/`（hub = assets/skillhub）。
- `scripts/new_experience.py`：`--title/--area/--summary/--tags/--hub` 生成骨架（含章节提示注释）、按标题查重、追加索引；`--validate` 校验 frontmatter 字段 + 五个必需章节 + emoji + TODO 占位。已冒烟验证创建、查重、索引写入、校验四条路径。
- references 三份：`format-spec.md`（章节定义 + 合格示例 + 不合格写法对照）、`extraction.md`（7 类信号 + 价值五问 + 不沉淀清单）、`promotion.md`（去向决策表：experiences / 新 skill / CODEBUDDY.md / memory 日志）、`skill-authoring.md`（init_skill.py、渐进披露、frontmatter 规则、反哺已有 skill 用增量修改）。
- 内置红线：不写评价性文字、根因必须落到文件:行或规范条款、禁止 emoji、一条只讲一件事。

用户要求的沉淀格式即「背景、表现、根因、解决、相关改动」，后续写经验一律按此结构。
