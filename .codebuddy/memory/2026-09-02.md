## 列表复制/选中行为改造（desktop 编辑器）

需求（用户确认的最终形态）：
- 选中列表项内文字复制 → 纯文本（行内格式保留），不带 `- `。
- 点圆点/序号 → NodeSelection 选中整个列表项，复制得 `- 文本`/`1. 文本`（视觉要像普通选区）。
- 块边界对齐拖选 / Cmd+A → 保留完整 Markdown 结构。

实现要点（有长期参考价值）：
- 剪贴板序列化在 `desktop/src/lib/editor/serializeSliceToMarkdown.ts`：**不要用 ProseMirror slice 形状（openStart/openEnd）启发式推断**——语义随切割深度变化，第一版因此有 bug（跨块部分选区边缘块带出 `## ` 前缀）。改为直接用 doc 位置算覆盖：`doc.forEach` 顶层块，完整覆盖 → `node.toJSON()`；被切开 → `nodesBetween` 提取行内 JSON（带 marks）包成裸 paragraph。
- `SectionEditor.tsx` 的 `clipboardTextSerializer` 忽略 slice 参数，走 `serializeSelectionToMarkdown(ed)`（NodeSelection 整项裸 listItem 需包回父列表）；`transformCopied` 负责 text/html 同样包回 `<ul>/<ol>`；跨段复制的 `getText` 走 `serializeRangeToMarkdown(editor, from, to)`。
- 圆点/序号是 CSS 原生 marker（非 DOM），不可选中；方案是 `listMarkerSelection.ts` 的 widget decoration 热区（`Decoration.widget(pos+1, {side:-1, key:...})`，key 带 pos 防复用错位，mousedown preventDefault+stopPropagation 防 PM/原生选区干扰、防干扰跨段选择 coordinator）。
- 视觉（vscode-theme.css）：`li.ProseMirror-selectednode` 不用默认 2px 外框，用 `background + box-shadow:-2em 0 0 0` 同色带（box-shadow 与元素背景同层，marker 字形仍在色带上方且两区零色差）；热区悬停用 `--vscode-editor-inactiveSelectionBackground`（选区预览色），cursor 用 default。
- 编辑器内所有文本高亮是 `.cross-section-selected` decoration 画的（原生 ::selection 全局禁用），NodeSelection 不会被 sectionHighlightSelection 镜像。

用户偏好：对方案"hack 程度"敏感，会先质疑再确认；偏好"完整覆盖才带结构"的严格可预测规则，而非 Notion 式中间项保留结构。

## 追加（同日晚）：视觉断层根因与 CSS 回退事件

- 用户曾把 `vscode-theme.css` 手动回退到第一版（TS 改动全部保留）——发现文件与记忆不符时必须先重读再改，不能按记忆编辑。
- "序号高亮与文字高亮断层"的真正场景：**拖选文字跨过列表项时正文亮、序号排水沟不亮**（镜像高亮 `Decoration.inline` 只画文本范围；原生 ::selection 全局禁用）。修复：`sectionHighlightSelection.ts` 的 `buildDecorations` 里，为 `from <= pos+1 && to > pos+1` 的 listItem 追加 `Decoration.node(pos, pos+size, {class:'list-item-lead-selected'})`，CSS 用 `li.list-item-lead-selected::before`（absolute, left:-2em, width:2em）点亮排水沟，颜色同 `--vscode-editor-selectionBackground`。镜像与跨段两条路径共用该函数，Cmd+A 全选同样生效。
- 三个视觉态几何统一为同一条 [-2em, 0] 左带：hover 预览（热区 background）、lead 高亮（::before）、marker 点击选中（li background + box-shadow:-2em 平移）。均与 `ul/ol` 的 2em padding 对齐；热区用 top:0/bottom:0 整条带，不依赖行高猜测。
- 注意：`FormatBubbleMenu.shouldShow` 已排除 NodeSelection（不会在点序号时弹工具栏）。

## 追加：标题被顶部 tab 胶囊遮挡修复

- 问题：笔记滚到顶部时 H1 标题被悬浮 tab 胶囊遮住约 10px。根因：`AppTitleBar`（absolute, h-9=36px）内的 tab 胶囊（高约 46px）用 `translate-y-1/2` 横跨 title bar 下缘，胶囊底部伸到窗口顶部往下约 59px；而 `DocumentPanel.tsx` 标题容器仅 `pt-12`（48px）。
- 修复：编辑模式标题容器 `pt-12` → `pt-16`；静态/只读模式滚动容器 `pt-8` → `pt-16`（同一问题的另一实例）。
- 布局常量备忘：tab 胶囊底部 ≈ 59px（title bar 36px + capsule 半高 23px）；`TAB_BAR_OVERLAY_HEIGHT=64` 是 overlay webview 高度。
